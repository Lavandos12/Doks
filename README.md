# Doks (Eluma) v1.0

> **Doks** — локальная (local-first) закрытая совместная площадка для команды из 4 человек: markdown-заметки с вики-ссылками `[[так]]` (Obsidian-стиль) и бесконечная доска со стикерами, текстом, рамками и стрелками (Miro-стиль). Работа в браузере в реальном времени без выделенного сервера — агенты синхронизируются друг с другом по защищенной сети **Radmin VPN** с помощью CRDT (**Yjs**).

---

## 1. Возможности системы

### Заметки (Notes)
- Иерархическое дерево папок с мягким удалением в корзину и переносом заметок.
- Редактор Markdown на базе **CodeMirror 6** с автодополнением вики-ссылок `[[название]]` по существующим заметкам.
- Автоматический переход по `[[ссылке]]` при клике и авто-создание целевой заметки, если она еще не создана.
- Боковая панель обратных ссылок (Backlinks).
- Мгновенный локальный поиск **MiniSearch** по названиям и содержимому файлов.

### Бесконечная доска (Board)
- Масштабирование (zoom колесиком мыши и кнопками) и панорамирование (drag фона / пробел).
- Объекты: стикеры с галочкой «сделано», текстовые блоки, рамки-группы (frames) и карточки заметок (двойной клик открывает связанную заметку).
- Палитра цветов (1..6) по спецификации Obsidian Canvas.
- Соединительные линии и стрелки со стрелочными наконечниками и подписями.
- Локальный Undo/Redo (`Y.UndoManager`) только для собственных действий.
- Отображение присутствия (Awareness): цветные курсоры соавторов с их именами и аватарками.

### Хранение на диске и Obsidian
- Рабочая папка: `%USERPROFILE%\Eluma\` (настраивается в конфиге).
  - `vault/` — читаемое зеркало обычных файлов:
    - Заметки в формате `.md` с YAML frontmatter (`id`, `title`, `updatedAt`).
    - Доски в стандартном формате JSON Canvas (`boards/*.canvas`), которые **напрямую открываются и редактируются в Obsidian**.
  - `.eluma/state/` — бинарные снимки Yjs (источник истины). Запись атомарная (через `.tmp` файл с переименованием).
  - `.eluma/snapshots/` — история снимков (каждые 10 минут) с ротацией.

### Сеть и безопасность
- Локальный Fastify-сервер привязан исключительно к `127.0.0.1` с проверкой заголовков `Host` и `Origin` (защита от DNS-rebinding и вредоносных сайтов в браузере).
- Пир-сервис слушает порт `4747` только на адаптере Radmin VPN (подсеть `26.0.0.0/8`, автоопределение интерфейса).
- Взаимное рукопожатие challenge-response на базе **HMAC-SHA256** по 32-байтному командному ключу (`teamKey`). Попытки подключения с чужим ключом немедленно отклоняются.
- Mesh-топология: автоматическое переподключение с экспоненциальной задержкой (1с..30с), дедупликация соединений и транзитная ретрансляция обновлений (A <-> B <-> C).

## 2. Быстрый старт на чистой Windows-машине (5 минут)

### Шаг 1. Radmin VPN
1. Установите [Radmin VPN](https://www.radmin-vpn.com/) и войдите в общую сеть вашей команды (каждому компьютеру присвоится IP вида `26.x.x.x`).

### Шаг 2. Разрешение порта в брандмауэре Windows
Откройте командную строку (`cmd.exe`) **от имени администратора** и выполните команду:
```cmd
netsh advfirewall firewall add rule name="Doks Peer Service" dir=in action=allow protocol=TCP localport=4747 remoteip=26.0.0.0/8
```
*(Эта команда разрешает входящие TCP-подключения к порту 4747 только из защищенной подсети Radmin VPN `26.0.0.0/8`).*

### Шаг 3. Запуск приложения
Запустите скрипт:
```cmd
start.bat
```
Либо через npm:
```cmd
npm run build
node agent/dist/index.js
```
Браузер автоматически откроется по адресу `http://127.0.0.1:3000`.

### Шаг 4. Добавление участников
1. Первый участник на экране «Сеть» копирует готовую строку-приглашение вида:
   `doks://26.153.49.48:4747#<teamKey>`
2. Остальные 3 участника переходят на экран «Сеть», вставляют эту строку в поле «Добавить пир» и нажимают кнопку.
3. Соединение мгновенно устанавливается и данные синхронизируются.

### Шаг 5. Автозапуск (по желанию)
Чтобы Doks запускался автоматически при входе в Windows, запустите:
```cmd
scripts\install-autostart.bat
```
*(Для удаления автозапуска запустите `scripts\uninstall-autostart.bat`).*

---

## 3. Открытие хранилища в Obsidian
1. Откройте Obsidian.
2. Нажмите «Open folder as vault» («Открыть папку как хранилище»).
3. Выберите папку `%USERPROFILE%\Eluma\vault`.
4. Все заметки и доски в папке `boards/` будут отображаться и работать со связями в Obsidian!

## 5. Структура монорепозитория

```
Doks/
├── package.json              # Конфигурация workspaces
├── tsconfig.base.json        # Базовый конфиг TypeScript
├── start.bat                 # Запуск агента и браузера
├── README.md                 # Руководство пользователя
├── shared/                   # Общие типы, схемы данных, протоколы
│   ├── src/types.ts          # Модели NoteMeta, BoardNodeData, PeerStatus
│   ├── src/schema.ts         # Yjs-хелперы и ключи Y.Map
│   ├── src/protocol.ts       # Сообщения пир-протокола (Handshake, Sync, Relay)
│   └── src/canvas.ts         # Спецификация Obsidian JSON Canvas (.canvas)
├── agent/                    # Node.js P2P агент
│   ├── src/agent.ts          # Главный фасад агента
│   ├── src/config.ts         # Загрузка/сохранение .eluma/config.json
│   ├── src/security.ts       # HMAC-SHA256 рукопожатие, генерация ключей
│   ├── src/network.ts        # Автоопределение IP Radmin VPN (26.0.0.0/8)
│   ├── src/storage/          # DocManager, StateStore, FileMirror, Snapshots, FileWatcher
│   ├── src/peer/             # PeerService, PeerConnection (WS сервер и клиент, Mesh)
│   └── src/server/           # Fastify: статика, REST API, WebSocket-мост для браузера
├── web/                      # Веб-клиент (Preact + Vite + CodeMirror 6)
│   ├── src/components/notes/ # Редактор заметок, [[wikilinks]], backlinks
│   ├── src/components/board/ # Бесконечный холст, стикеры, стрелки, сетка
│   ├── src/components/network/# Экран участников и сети (пиры, invite string)
│   └── src/components/history/# Снимки состояния и корзина
├── scripts/                  # Скрипты автозапуска Windows
└── tests/                    # Интеграционные тесты (Vitest)
```
