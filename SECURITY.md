# Security Policy

Doks takes the security and privacy of user data seriously. As a local-first application, user data is stored on local disks and transmitted directly peer-to-peer over authenticated connections without cloud intermediaries.

---

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0.0 | No |

---

## Reporting Vulnerabilities

If you discover a security vulnerability within Doks, please report it privately:
1. Do **not** open a public issue.
2. Submit a private vulnerability advisory on GitHub or email the maintainers at `security@doks.app`.
3. Provide a clear description, reproduction steps, and potential impact.

Maintainers will respond within 48 hours to confirm receipt and begin mitigation.
